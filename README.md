## 🛒 Overview
This bakery shopping website, built primarily with vanilla JavaScript, utilizes HTML for structure, CSS with float-based positioning for layout, and integrates FormSpree for handling form submissions, offering a fully functional and styled user experience.

## 🚀 Technologies Used

| Tech     	| Description                                                             	|
|--------------|-----------------------------------------------------------------------------|
| **HTML** 	| 🧱 Structures the content and layout of the bakery website.             	|
| **CSS**  	| 🎨 Adds styling and layout using **float-based positioning**.           	|
| **JavaScript** | ⚙️ Powers interactive features and dynamic behavior.                 	|
| **FormSpree** | 📬 Simplifies contact and order form submissions.                      	|

<br>

## ✨ Features

- 🍩 Clean, responsive design with floating layout elements.
- 🛍️ Dynamic interactions powered by JavaScript.
- 📦 Easy form submissions using FormSpree.
- 🎯 Focused on a **vanilla** tech stack — no frameworks required!
